# webpprof documentation

- [MCP server](mcp.md) — install `webpprof-mcp` and connect Codex, Claude,
  Cursor, or another MCP client.
- [Integrations](integrations.md) — connect HTTP frameworks, RPC, databases,
  caches, queues, messaging systems, loggers, mail, and OpenTelemetry.
- [Configuration](configuration.md) — retention, limits, sampling, selective
  capture, storage, import, and export.
- [Dashboard](dashboard.md) — compose built-in and custom runtime widgets.
- [Security](security.md) — bind, authenticate, redact, and remove captures.
- [Correlation and findings](correlation.md) — propagate request context, use
  tags, time middleware, and interpret automatic findings.
- [Event reference](event-reference.md) — manual logging APIs, `Meta`, entity
  fields, request-related operations, and background work.
- [SQL profiling](sql-profiling.md) — capture callsites, source links, EXPLAIN,
  and Go replay skeletons.
- [Custom profilers](custom-profilers.md) — implement an integration adapter.

Start with the repository [README](../README.md) for installation and a minimal
working example.
